# Каталог фильмов (Movies API)

Проект с воркшопа по разработке REST API для каталога фильмов на FastAPI и SQLAlchemy.

## Описание проекта

Сервис предназначен для управления базой данных фильмов. Реализованы базовые CRUD-операции, фильтрация списка по параметрам, сортировка, пагинация и валидация данных. Проект использует асинхронную работу с базой данных SQLite через SQLAlchemy.

## Основные возможности приложения

- Добавление, просмотр, обновление и удаление фильмов (CRUD)
- Частичное обновление данных фильма через PATCH
- Фильтрация по году выпуска и минимальному рейтингу
- Сортировка по полям (название, год, рейтинг, id) в прямом и обратном порядке
- Постраничная пагинация с ограничением размера выборки (limit, offset)
- Валидация входных данных через схемы Pydantic
- Ограничения на уровне базы данных (CheckConstraint)
- Управление структурой БД через миграции Alembic
- Автоматическая документация через Swagger UI (/docs)

## Технологический стек

- Python 3.12+
- FastAPI
- Uvicorn
- SQLAlchemy 2.0 (асинхронный режим)
- aiosqlite
- Alembic
- Pydantic v2

## Быстрый старт

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_репозиторий>
cd moves_api
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv
```

- Windows:
```bash
venv\Scripts\activate
```
- Linux / macOS:
```bash
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Применение миграций
```bash
alembic upgrade head
```

```bash
uvicorn src.main:app --reload
```

После запуска сервер доступен по адресу `http://127.0.0.1:8000`.  
Интерактивная документация: `http://127.0.0.1:8000/docs`.

## Основные эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | / | Проверка работы сервиса |
| GET | /movies/ | Получить список фильмов (с фильтрацией и пагинацией) |
| GET | /movies/{movie_id} | Получить фильм по ID |
| POST | /movies/ | Добавить фильм |
| PUT | /movies/{movie_id} | Полное обновление фильма |
| PATCH | /movies/{movie_id} | Частичное обновление фильма |
| DELETE | /movies/{movie_id} | Удалить фильм |

## Фильтрация и сортировка

Для эндпоинта `GET /movies/` доступны следующие query-параметры:

- `year_min` — минимальный год выпуска
- `year_max` — максимальный год выпуска
- `min_rating` — минимальный рейтинг
- `order_by` — поле сортировки: `title`, `-title`, `year`, `-year`, `rating`, `-rating`, `id`, `-id` (минус означает сортировку по убыванию, по умолчанию `-rating`)
- `limit` — количество записей (по умолчанию 50, максимум 100)
- `offset` — смещение списка (по умолчанию 0)

Пример запроса:
```http
GET /movies/?year_min=2000&year_max=2024&min_rating=7.0&order_by=-rating&limit=10
```

## Модель данных

Поля сущности Movie:

- `id` (int) — идентификатор (первичный ключ)
- `title` (str) — название фильма (от 2 до 200 символов)
- `genre` (str) — жанр (от 2 до 100 символов)
- `rating` (float) — рейтинг от 0.0 до 10.0
- `year` (int) — год выпуска (от 1888 до текущего года)

## Ограничения базы данных

В таблице `movies` заданы следующие ограничения:

1. Рейтинг: `rating >= 0 AND rating <= 10` (значение рейтинга от 0 до 10).
2. Год выпуска: `year >= 1888` (не раньше 1888 года, когда появился кинематограф).
3. Поля `title`, `genre`, `rating`, `year` обязательны для заполнения (`nullable=False`).
